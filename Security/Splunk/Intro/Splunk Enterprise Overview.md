default roles
- admin
	- install apps
	- ingest data
	- create knowledge objects
- power user
	- can create knowledge objects for all users within app
	- can perform realtime searches
- user
	- can only see their own knowledge objects 

[splunkbase](https://splunkbase.splunk.com/) offers apps but you can create your own
- ex: search and reporting
	- default interface for searching and analyzing data
	- can break down data in hosts (hostname, ip, FQDN, etc.), sources (ex: port, file, directory path, etc.), and sourcetypes (classification of data)
